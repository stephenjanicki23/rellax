# Game data

All money values are in **thousands of US dollars** (`95500` = $95.5M).

| Folder | File | What it holds |
| --- | --- | --- |
| `league_rules/` | `rules.json` | Versioned CBA and cap rules by season |
| `contracts/` | `contracts.json` | Real player contracts (keyed by NHL player id) |
| `transactions/` | `dead_cap.json` | Existing dead-cap charges (buyouts, retained salary, overages) |
| `draft/` | `picks.json` | Who owns every future draft pick (traded picks and their conditions) |
| `draft/` | `class.json` | Real draft prospects from NHL Central Scouting rankings |
| `prospects/` | `reserves.json` | Each club's unsigned draft picks (reserve list) with sign-by dates |
| `nhl/` | `rosters.json` | Real rosters, coaches and GMs (from `scripts/fetch-nhl.mjs`) |
| `players/`, `teams/` | — | Reserved for future imports |

The game reads these files at build time. To refresh the data, replace a file and rebuild; no code changes are needed.

## `league_rules/rules.json`

Each season under `seasons` inherits from the previous one, so a season only lists what changes. Seasons past the end of the table are projected with `projection.annualGrowth` and flagged `projected`.

Every value carries a `source`:

- `CBA2013`: the 2013 CBA as amended in 2020 (rules through 2025-26).
- `MOU2025`: the June 2025 memorandum (the new CBA from 2026-27).
- `NHL`: published league figures.
- `PROJECTED`: not published yet. Update these when the league announces the figure.
- `SIMPLIFICATION`: a game simplification of a more detailed rule.

The UI and the rules engine show these provenance tags, so a rule's origin stays visible.

## `contracts/contracts.json`

Generated by `npm run fetch:contracts` (`scripts/fetch-contracts.mjs`) from CapWages (capwages.com):

1. Read all 32 team pages, which list every player in each organisation (NHL roster, minors, injured reserve, dead cap).
2. Read each player's page for his full contract history.

Raw pages are cached in `scripts/.cache/capwages` (git-ignored). Re-runs only fetch missing pages; pass `--refresh` to start over.

```jsonc
{
  "schemaVersion": 2,
  "asOf": "2026-10-03",
  "source": "CapWages (capwages.com) player contract pages",
  "players": [
    {
      "nhlId": 8477956,               // matches the roster snapshot
      "name": "David Pastrnak",
      "teamAbbr": "BOS",
      "status": "NHL",                // NHL | Minor | Junior | IR | SOIR | LTIR | SEIR | Loan | ...
      "born": "May. 25, 1996", "pos": "RW", "shoots": "R", "nationality": "CZE", "number": 88,
      "firstSpcAge": 18, "firstSpcSeason": 2014, "careerGames": 764,
      "contracts": [                   // every contract, oldest first
        {
          "type": "standard",          // "standard" | "ELC"
          "extension": true,
          "signingTeamAbbr": "BOS",
          "signingDate": "Mar. 2, 2023",
          "signedSeason": 2022,        // league year of the signing (July 1 rollover)
          "expiryStatus": "UFA",
          "capHit": 11250,             // official cap hit (performance bonuses excluded)
          "totalValue": 90000,
          "twoWay": false,
          "years": [{ "season": 2023, "salary": 7500, "signingBonus": 5000, "perfBonus": 0 }],
          "clauses": [{ "kind": "NMC", "from": 2023, "to": 2028 }, { "kind": "M-NTC", "from": 2028, "to": 2030, "teams": 10, "mode": "block" }],
          "retained": [{ "teamAbbr": "TOR", "pct": 0.25 }],
          "boughtOut": false
        }
      ]
    }
  ]
}
```

At league creation the engine:

- **Picks contracts:** the contract in force (the most recently signed if two overlap), any signed extension, and the rest as contract history.
- **Places players** on the NHL roster or in the minors from `status`, and creates contracted organisation players missing from the roster feed (AHL, LTIR), estimating their ratings from their contract and experience.
- **Handles injuries:** IR, SOIR and LTIR players start injured. LTIR players are placed on LTIR with relief, and clubs over the cap use LTIR on injured players the way NHL teams do.

Imported contracts are marked `source: "real"` and are never rescaled. The few players without a record (generated depth or prospects) get structurally valid estimates marked `source: "estimated"`.

## `transactions/dead_cap.json`

```jsonc
{
  "schemaVersion": 1,
  "charges": [
    { "teamAbbr": "SJS", "season": 2026, "amount": 1666.67, "kind": "buyout", "playerName": "Martin Jones", "nhlId": 8474889, "note": "This contract was bought out (...)" }
  ]
}
```

`kind` is one of `buyout`, `bonusOverage`, `thirtyFivePlus`, `termination`, `recapture` or `other`. Salary retained on traded players belongs in the contract record (`retained`), not here.

## Refreshing contract data

Run `npm run fetch:contracts`, then rebuild. The cap page shows the database date under "Rules in force".

## `draft/picks.json` and `prospects/reserves.json`

Generated by `npm run build:draft` (`scripts/build-draft.mjs`) from the cached CapWages team pages, so run `npm run fetch:contracts` first.

- **picks.json**: one row per pick, giving `year` (NHL draft year), `round`, `original` and `owner` team abbreviations, and any `conditions` (for example "Top-10 protected"). In the game a pick's `season` is the season whose draft it belongs to, so draft year = `season + 1`. When a "Top-N protected" pick lands inside its protection, it stays with the original team and the next year's pick of the same round goes to the owner instead (SIMPLIFICATION: real conditions vary).
- **reserves.json**: unsigned draft picks, with name, birth date, position, draft year/round/overall and `mustSignBy`. They enter the game as prospects with no contract. Ratings are estimated from draft slot and age, because unsigned picks have no public ratings. Clubs must sign them by the deadline, or the rights lapse and the player becomes a free agent. When no deadline is listed, the rights are held until age 27 (SIMPLIFICATION).

## `draft/class.json`

Generated by `npm run fetch:draftclass` (`scripts/fetch-draft-class.mjs`) from NHL Central Scouting rankings (api-web.nhle.com). It lists prospects for the game's first draft (`draftYear` = the start season + 1) with list, rank, club, league, birth date and measurements.

- Once Central Scouting has published the year's rankings (preliminary in the fall, midterm in January, final in April), every ranked prospect is included, and the game fills the rest of the class with generated players.
- Until then, the file holds prospects ranked the year before who went undrafted (`reentry: true`). These players are eligible again. The first-time-eligible class is generated.
- Ability is estimated from list rank and age, because draft prospects have no public ratings.

Re-run the script after each Central Scouting release.
